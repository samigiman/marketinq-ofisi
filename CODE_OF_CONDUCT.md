# Davranış qaydaları / Code of Conduct

Bu layihə [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) qaydalarını qəbul edir.

**Qısaca:** hər kəsə hörmətlə yanaşın, fikir ayrılığını işə yönəldin, şəxsə yox. Təhqir, təqib, ayrı-seçkilik və başqasının şəxsi məlumatını paylaşmaq qadağandır.

**In short:** be respectful, critique ideas rather than people. Harassment, insults, discrimination and sharing others' private information are not tolerated.

Qayda pozuntusunu GitHub-da layihə sahibinə şəxsi mesajla bildirin. Bütün müraciətlər məxfi saxlanılır.
Report violations privately to the project maintainer on GitHub. All reports are kept confidential.
